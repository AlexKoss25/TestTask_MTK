# SQL Store — мини-хранилище SQL-запросов

## Как развернуть

1. Скопировать папку `sql_store` в директорию веб-сервера (например, XAMPP -> htdocs).
2. Настроить подключение к базе в файле `includes/db.php`:

   $host = 'localhost';
   $db   = 'sql_store';
   $user = 'root';
   $pass = 'ваш_пароль';

3. Создать базу `sql_store` в MySQL/MariaDB.
4. Импортировать файл `sql_store.sql` через phpMyAdmin — это создаст таблицы и добавит тестовые данные.
5. Открыть в браузере: `http://localhost/sql_store/public/index.php`

## Особенности

- AJAX: добавление, редактирование, удаление и выполнение запросов без перезагрузки страницы.
- Bootstrap 4.3 для стилей, jQuery 3 для AJAX.
- Результаты выполнения SQL выводятся в виде HTML-таблицы.
- Форма добавления/редактирования появляется в блоке под таблицей (`#form-container`).

## Замечания и возможные улучшения

1. **Большое количество запросов**: если в базе будет много записей (например, 100+), страница станет длинной, кнопки «Редактировать/Удалить/Выполнить» окажутся далеко.  
   Возможные улучшения:
   - Пагинация таблицы
   - Фильтрация по пользователю или названию запроса
   - Скролл с фиксированными заголовками и кнопками

2. **Подсветка изменений**: можно добавить визуальные эффекты после редактирования или удаления строки.

3. **Модальные окна**: формы можно показывать в модальном окне, чтобы не использовать отдельный блок под таблицей.

4. **Логирование ошибок SQL**: сейчас ошибки выводятся в alert или блок, можно сохранять их в лог.

## Тестовые данные

- 2 пользователя: Alice и Bob
- Несколько запросов с разными названиями
- SQL-дамп: `sql_store.sql` (создаёт таблицы и вставляет тестовые данные)
